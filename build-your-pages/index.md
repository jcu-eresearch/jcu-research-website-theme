Plan each page around what visitors need to understand or do. A short methods page may need only headings and paragraphs; a project homepage may need an introduction, findings, and links to more detail.

1. [Choose a layout]({{ "/build-your-pages/choose-a-layout/" | relative_url }}) — Choose a standard page or a landing page for its purpose.
2. [Understand content blocks]({{ "/build-your-pages/content-blocks/" | relative_url }}) — Group related information and arrange it in reading order.
3. [Combine writing methods]({{ "/build-your-pages/combine-writing-methods/" | relative_url }}) — Use Markdown, YAML blocks, layout classes, and HTML together.
4. [Build a landing page]({{ "/build-your-pages/landing-page-styles/" | relative_url }}) — Create a hero and ordered project overview sections.

You do not need to learn every method before building a page. Start with plain Markdown and add the layout features your content needs. Use [Content block recipes]({{ "/reference/content-block-recipes/" | relative_url }}) to find a pattern by what you want to display.
