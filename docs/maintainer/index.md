# Maintaining the theme

These guides are for administrators and contributors maintaining this repository. They are stored with the code and excluded from the Jekyll website build. The website documentation for research teams remains in its existing sections.

- [Development workflow](development-workflow.md): create a branch, make and test changes, open a pull request, merge into main and clean up.
- [Dependency updates](dependency-updates.md): decide when to update the build tools, review Gemfile and lockfile changes, and verify compatibility.
- [Creating a release](creating-a-release.md): test a release candidate, publish an immutable tag and GitHub Release, update the starter, and handle fixes or rollback.

Maintain these Markdown files alongside the changes they describe. Word copies are convenient reference documents; these repository guides are the primary maintained instructions. Keep credentials and private organisational procedures in the team's secure documentation location.
